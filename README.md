# Igusa — investor demo

A clickable web prototype of an iPhone + Apple Watch symptom logger, with sample data.
Live: https://bradleymachado.github.io/igusa-demo/

## Run locally

```sh
npm ci
npm run dev
npm test
npm run e2e
```

Prototype. Sample data. Not medical advice.
